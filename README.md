# Sivatagi GTA

Felülnézetes, GTA-szerű böngészős játék: egy karakter és egy piros autó a sivatagban, villanyoszlopokkal és nappal/éjszaka váltással (30 perc nappal, 30 perc éjszaka).

## Indítás
Nyisd meg az `index.html`-t a böngészőben – nincs szükség telepítésre.

## Irányítás
| Gomb | Funkció |
|---|---|
| WASD / nyilak | mozgás / vezetés |
| Shift | futás |
| E | be- / kiszállás |
| Space | kézifék |
| T | gyorsított idő (60x) |
