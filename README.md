# Sivatagi GTA

Felülnézetes, GTA-szerű böngészős játék egy hatalmas (~55 000 × 55 000 px-es) sivatagban: piros autó, lövöldözés, AI gyalogosok (járdán sétálnak, zebrán kelnek át), banditák és AI autók, nyálkafoltok az utakon, rendőrségi üldözés 60 km/h feletti gyorshajtásért, homokviharok, villanyoszlopok és nappal/éjszaka váltás (30 perc nappal, 30 perc éjszaka).

Élő verzió: https://voparin.github.io/gta-game/

## Indítás
Nyisd meg az `index.html`-t a böngészőben – nincs szükség telepítésre.

## Irányítás
| Gomb | Funkció |
|---|---|
| WASD / nyilak | mozgás / vezetés |
| Shift | futás |
| E | be- / kiszállás |
| Space | kézifék (drift, féknyom, füst) |
| Bal klikk / F | lövés (egérrel célzás) |
| H | homokvihar be/ki |
| T | gyorsított idő (60x) |
| Esc | menü: szünet, szkin- és autóváltás (a választás megmarad) |

## Rendőrség
- Az utakon (és járdán) **60 km/h** a sebességkorlát – a táblák is jelzik. Ha túlléped, körözni kezdenek (★), rendőrre lövésért ★★.
- **Lerázás:** ha 12 másodpercig egy rendőrautó sincs a közeledben, leszállnak rólad.
- **Letartóztatás:** ha megállsz és egy rendőrautó melléd ér, letartóztatnak, és a kezdőhelyen folytatod.
